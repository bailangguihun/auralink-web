# 知识库全量浏览

本版本替代旧界面中的统计说明、图谱来源折叠、图中前 N 项、说明、数据表和查看数值入口。页面不新增辅助说明小字，名称、数值、搜索、排序和翻页直接构成图表浏览界面。既有统计口径不变；空值和未公开字段不补作真实数据。

## Core 配套接口

`GET /api/v1/knowledge/painting-statistics` 继续提供兼容旧版的摘要及覆盖信息。

新 Web 的七个指标都使用经过身份认证的
`GET /api/v1/knowledge/painting-statistics/{metric}`：

- `metric`：geography、dynasty、category、style、imagery、sentiment、sentimentByDynasty。
- `page` 从 0 开始，`size` 为 1–200。
- `q` 为最多 200 字的字面量搜索，涵盖完整指标。
- `sort` 为 value、name 或 chronological；同值有稳定名称排序。
- 可传 `revision`。聚合已改变时返回 409，Web 只自动恢复一次首屏，避免混合版本。
- 返回 `schemaVersion / metric / items / page / size / totalItems / totalPages / hasMore / revision`。

旧 Core 没有此接口时，不能声称支持全量浏览。兼容上线顺序为先发布 Core，再发布 Web。

## 展示与隔离

国画顶部使用“国画作品数”和“作者名称数”；诗词页复用同款两张卡，展示“诗词作品数”和“作者名称数”。诗词作品数沿用已校验快照 `overview.poems` 的分类口径（节点类别包含“诗词”），作者名称数对类别包含“诗人”的非空名称去除首尾空白后去重。当前快照分别为 186、218；不会把 711 个全部实体当作作品数，也不随邻域选择或实体分页变化。这是现有混合分类的统计，并非经过书目核实的诗作或作者总数；卡片 title 提供口径，不新增说明小字。数据未就绪时显示骨架，失败时沿用错误态，不用零值代替未取得的统计。

地域、朝代采用可滚动条形列表，分类和配乐情感保留紧凑图表；风格采用可搜索排行，意象采用带词频的词条区，朝代情感采用 0–100 点图。大型指标按页读取，项目数量不限于旧版的 100 项。每页名称完整换行、数值直接展示；操作控件使用正常字号。

账号改变、查询改变或组件卸载时取消旧请求；迟到响应不能更新新账号或新查询。只进行读取，不自动提交业务操作。暂不合并原始朝代描述。

诗词页签直接显示关系图，不再展示图谱介绍卡及实体搜索、类别筛选、重置筛选栏。图谱默认保留全部实体与关系。关系标签的独立搜索、排序及分页继续保留，取消 Top N 和“其余”聚合；实体类别保持完整图例。实体索引保持分页及点选邻域。只有选中节点或关系后才出现详情区域。

图谱保留全量节点和边，提供适应全图、缩放、展开视图。首次布局、进入或退出邻域后及主动复位按节点实际位置适配视野；用户拖动或缩放后不自动抢回视野。节点布局读取适配器集中在 `knowledge-charts.tsx`，升级 ECharts 时须运行真实图谱浏览器回归。
