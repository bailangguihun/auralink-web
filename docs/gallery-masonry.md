# 画廊横排与加载更多

画廊改为按完整横排追加，每行卡片底边一致。同行预览框等高，框宽优先按画幅比例分配；
极窄画幅保留纸边；缩略图在贴合原始画幅的内层窗口中居中放大 8%，裁去少量边缘，减少原图黑框。原先按最短列排布及最多缩小 15% 的逻辑已移除。

## 排版与图片

- `lib/gallery-rows.ts` 使用连续动态规划，为正常批次选择每排 2–6 幅；同一排含间距填满容器，
  顺序不变、不隐藏尾图。图片高度和卡片信息区高度分别统一，因此同行卡片底差应不超过 1px。
- 容器宽度不超过 680px 时单列；较宽容器卡片宽度下限 120px，超过 900px 为 140px。
  极端画幅宽高比仍限于 1/2.2 至 2.5；不足最小宽度的框通过纸边扩宽。整批只有 1–2 幅时居中，
  避免过度放大。标题最多两行，作者和标签省略，完整信息在详情。
- 正常 12 幅追加独立排版，保持已有行位置。末批仅 1–2 幅时合并上一批最后一排，之前的行不变。
  窗口尺寸变化会按新宽度重新排版。没有 ResizeObserver 时使用 window resize 事件。
- API 有有效尺寸时直接预留框架；缺尺寸时并行读取本批图片的自然宽高，准备好后整批展示。
  每张尺寸读取最多等待 8 秒，失败或超时采用 4:3 框；图片随后出现也不会改变已提交行的高度。
  加载期间使用等高骨架；尺寸缓存仅在浏览器内存保留最多 1000 个公共媒体比例。
- 仅画廊列表缩略图放大裁边，原始媒体和详情页保持原图展示；个人收藏继续原三列网格和固定图片框。收藏点击区 44px，位于信息区右下角；窄卡只显示首个分类标签，为标题与作者保留完整宽度。

## 每日一画

- `components/daily-painting.tsx` 使用单层横向展签，图片占桌面卡片的 42%、手机的 40%。
  常规卡片内容高 248px / 218px；长标题、错误说明或文字放大时允许自然增高。
- 图片在预留空间内等比完整展示，原始图片尺寸不会撑高模块；标题和画意各最多两行，手机也显示画意。
  右侧按每日一画与日期、作品名、作者朝代、画意、查看作品排列，整卡是一个可键盘操作的详情链接。
- 正式卡片与首屏骨架共用布局。无推荐时显示同一展签内的重试入口；图片失败保留文字及详情入口。
  已有推荐的刷新或失败状态保留内容，重试控件位于详情链接外。
- 每日推荐仍由 `GalleryScreen` 独立读取，日期沿用浏览器当前日期，不新增接口或生成荐语。

## 追加状态与恢复

- 后端仍按 page/size 返回，每次请求 12 幅。`useGalleryFeed` 区分首批与追加，按 paintingId 去重。
  下一页以服务端返回页号为准；成功后推进，失败在底部重试同一页，保留已有结果。
- 同步请求锁防止连点。筛选、排序、清除或同条件重新提交均重新读取首批，并取消旧请求；
  查询标识、AbortController 和登录 generation 共同隔离过期响应。每日推荐独立读取。
- 每日换序继续携带服务端 orderDate。Core 跨日返回新日期和 page 0 时，替换旧批次并提示，
  不把两天目录混在一起。401/403 清除不可继续展示的数据。
- 当前会话最近一次查询及批次在内存保存 20 分钟，不写磁盘、不缓存 token。详情返回恢复
  筛选和批次，并以可见作品及视口偏移恢复位置。用户主动滚动会取消尚未完成的自动定位。
  完整刷新、过期或登录身份变化会重新读取；这不是跨设备/跨会话的浏览历史。
- 底部显示实际已经排版展示的数量与 API 总数，按钮依次为“加载更多画作”“正在加载…”或
  “重试加载”；没有下一批时显示“已展示全部画作”。没有自动触底加载。
- 画廊整页关闭浏览器滚动锚定（包含列表外的加载按钮和页脚），避免追加骨架与画作时浏览器
  跟随页脚跳到底部。请求、尺寸准备、追加完成都保留当前视口；等待时可自由滚动，不强制滚回点击位置。

```bash

GALLERY_API_URL=http://127.0.0.1:4350 \
GALLERY_BROWSER_OUTPUT=/tmp/artlive-gallery-rows/browser \
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \

```

4350 不需启动服务，浏览器拦截所有 API，外部请求受阻；收藏仅在合成夹具执行。

跨日、详情往返、末批 1/2/5 幅、空结果、少量作品、极端比例、坏图、缺尺寸、
响应式和无 ResizeObserver。追加滚动回归使用真实鼠标/键盘操作，分别验证 API 等待、图片尺寸准备、
完成三个阶段的 scrollY 与旧画作视口偏移，并覆盖手机和等待时主动滚动。
旧加载回归的画廊场景已改为追加，个人收藏仍验证分页。
这些检查不能替代生产认证或真机 Safari 验收。开发预览运行时请在临时目录做构建，
避免覆盖正在被 next dev 使用的 .next。
